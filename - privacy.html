プライバシーポリシー

「暮らし整う収納アイデア」（以下「本サービス」）は、個人が運営する独立したサービスです。Pinterest、楽天グループ、その他の企業と提携・公認の関係にあるものではありません。本ポリシーでは、本サービスにおける情報の取り扱いについて説明します。

1. 運営目的

本サービスは、収納や暮らしに役立つ商品・アイデアを紹介するコンテンツを作成・管理し、運営者自身の Pinterest ビジネスアカウントで発信することを目的としています。

2. 取得する可能性がある情報

  • 運営者自身の Pinterest アカウントに関する情報（ボードの一覧、投稿した Pin の識別子など、投稿機能に必要な範囲）
  • Pinterest API の利用に必要な認証情報（アクセストークン、リフレッシュトークンなど）
  • 本サイトへのアクセス時に、ホスティングサービスが自動的に記録する技術情報（下記「7. アクセス解析・ホスティングについて」を参照）

本サービスは、閲覧者の氏名・メールアドレス・住所などの個人情報を入力していただく仕組みを設けていません。

3. 利用目的

取得した情報は、次の目的にのみ利用します。

  • 運営者が事前に確認・承認したコンテンツ（画像・タイトル・説明文・リンク）を、運営者自身の Pinterest アカウントへ投稿するため
  • 投稿の結果（投稿済みかどうか、Pin の識別子など）を記録し、二重投稿を防ぐため
  • 本サービスの不具合の確認と改善のため

4. Pinterest API の利用

本サービスの投稿管理ツールは、Pinterest が提供する API を利用します。利用する範囲は、運営者自身のアカウントにおけるボードの確認と Pin の作成・確認に限ります。第三者のアカウントを操作したり、第三者のデータを収集・分析したりすることはありません。

Pinterest API の利用にあたっては、Pinterest の定める利用規約・開発者向けガイドラインに従います。

5. OAuth 認証情報・アクセストークンの取り扱い

Pinterest API のアクセストークン等の認証情報は、次のとおり取り扱います。

  • 投稿機能など、本サービスの運営に必要な目的にのみ利用します。
  • 公開ページ（本サイトを含む）に表示しません。
  • 第三者へ販売・貸与・譲渡しません。
  • 運営者の管理する環境に保管し、ソースコードの公開リポジトリ、ログ、画面表示に含めないよう管理します。
  • 不要になった認証情報は、速やかに無効化または削除します。

6. 第三者提供

本サービスは、取得した情報を第三者に提供しません。ただし、法令に基づき開示が求められた場合はこの限りではありません。

7. アクセス解析・ホスティングについて

現在、本サイトではアクセス解析ツールや Cookie を利用した計測を行っていません。今後導入する場合は、本ポリシーを更新してお知らせします。

本サイトは GitHub Pages で公開しています。アクセス時の IP アドレスなどの技術情報は、GitHub によって記録される場合があります。その取り扱いについては、GitHub のプライバシーに関する説明をご確認ください。

8. アフィリエイトについて

本サイト・関連SNS（Pinterest など）では、楽天アフィリエイト等のアフィリエイトプログラムを利用する場合があります。紹介した商品のリンクから購入された場合、運営者が紹介料を受け取ることがあります。

アフィリエイトリンクを経由した購入では、リンク先の事業者（楽天グループなど）が、それぞれのプライバシーポリシーに基づいて Cookie 等の情報を取り扱う場合があります。

9. 外部サービスへのリンク

本サイトや関連SNSの投稿には、外部サービス（Pinterest、楽天市場など）へのリンクが含まれる場合があります。リンク先での情報の取り扱いは、各サービスのプライバシーポリシーに従います。本サービスは、リンク先の内容について責任を負いません。

10. 免責事項

本サービスで紹介する商品の価格・在庫・仕様などは、掲載時点の情報です。最新の情報はリンク先の販売ページでご確認ください。

投稿に使用している画像には、AI で生成した使用イメージが含まれる場合があります。実際の商品や設置状況とは異なる場合があります。

本サービスの情報を利用したことによって生じた損害について、運営者は責任を負いかねます。

11. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、本ページを更新し、制定日・更新日を明記します。
